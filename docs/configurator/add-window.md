# Как добавить изделие

Чтобы добавить новое изделие в заказ, откройте конфигуратор и нажмите кнопку **Добавить мягкое окно**.

![Кнопка добавления изделия](/images/configurator/add-window.svg)

## Когда использовать

Добавление нового изделия нужно, если в одном заказе несколько мягких окон с разными размерами или параметрами.

## Порядок действий

1. Откройте страницу конфигуратора.
2. Нажмите **Добавить мягкое окно**.
3. Укажите размеры.
4. Выберите материал, окантовку и крепления.
5. Проверьте чертёж.
6. Подтвердите изделие.
7. Перейдите к оформлению заказа.

## Частые ошибки

Если кнопка оформления заказа недоступна, проверьте, что все изделия подтверждены.
