# Конфигуратор

Конфигуратор помогает собрать заказ, добавить изделия, проверить параметры и перейти к оформлению.

## Основные действия

- Создать заказ.
- Добавить изделие.
- Отредактировать параметры изделия.
- Проверить итоговую конфигурацию.
- Перейти к оформлению заказа.
