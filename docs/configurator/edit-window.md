# Редактирование изделия

Откройте изделие из списка заказа, измените параметры и сохраните обновления.

## Что можно изменить

- Размеры.
- Материал.
- Окантовку.
- Крепления.
- Количество и дополнительные параметры.

## Проверка

После изменения параметров проверьте чертёж и итоговую стоимость перед оформлением заказа.
