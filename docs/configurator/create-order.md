# Создание заказа

Создание заказа начинается со страницы конфигуратора. Заполните базовые данные и перейдите к добавлению изделий.

## Порядок действий

1. Откройте конфигуратор.
2. Создайте новый заказ.
3. Укажите данные клиента или объекта, если они требуются.
4. Добавьте первое изделие.
5. Сохраните заказ.

## Рекомендации

Перед оформлением проверьте, что все изделия подтверждены и не содержат ошибок в параметрах.
